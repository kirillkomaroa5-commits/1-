# Трекер прочитанных книг

Консольное приложение для учёта прочитанных книг с возможностью добавления, просмотра, удаления и статистики.

## Как запустить

1. Клонируйте репозиторий.
2. Убедитесь, что у вас установлен Python 3.x.
3. Запустите приложение: `python main.py`.

## Пример работы

При запуске отображается меню:
1. Добавить книгу
2. Показать все книги
3. Показать среднюю оценку
4. Статистика по авторам
5. Удалить книгу
6. Выход
